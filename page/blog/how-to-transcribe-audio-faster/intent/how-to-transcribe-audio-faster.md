## Dữ liệu gốc (do tác giả cung cấp – không tự sửa số)

| Hạng mục | Số liệu |
|---|---|
| File 4 phút 53 giây | 4,19 giây |
| File 4–5 phút (nhiều lần đo) | 4–6 giây (dao động theo thời điểm) |
| File 1 giờ | 1 phút 19 giây; 1–2 phút tuỳ tải server giờ cao điểm |
| Upload file vs dán link nền tảng | Gần như không chênh lệch (4–5–6 giây) |
| Định dạng / dung lượng (MP3, MP4, bao nhiêu GB) | Không ảnh hưởng — tốc độ tính theo **thời lượng** audio/video |
| Ngôn ngữ | Không ảnh hưởng tốc độ; hỗ trợ hàng trăm ngôn ngữ |
| File dài hơn 1 giờ | Xử lý được, chậm hơn theo tỉ lệ thời lượng |
| Độ chính xác từ ngữ | ~95% |
| Lý do chính xác | Tách tiếng ồn và nhạc nền trước khi nhận diện; model đã train, chủ đề video không ảnh hưởng |
| Thao tác | 1–2 bước: upload hoặc dán link |
| So với Otter, TurboScribe | Tốc độ ngang nhau; tự tin hơn về độ chính xác (chưa có số đo so sánh) |

Góc nhìn của tác giả đưa vào bài:

- Tốc độ chỉ có ý nghĩa khi transcript chính xác, vì thời gian sửa mới là phần tốn nhất.
- Người dùng hay copy transcript để **tóm tắt video**, nhưng bỏ qua việc transcript đủ chính xác để **làm subtitle** luôn (có timestamp đi kèm).
